# Labs personales

Este repositorio contiene los laboratorios y experimentos que voy creando para practicar y aprender diferentes tecnologías. Cada carpeta corresponde a un proyecto o demo independiente.

- `hipotecario`: Demo de aplicación web para simulador hipotecario.

Puedes explorar cada carpeta para ver el código y los recursos de cada laboratorio.
